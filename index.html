01

Convocation Registration Dashboard

Tool: Google Sheets

I created a dashboard to bring convocation registration information into one view. It presents registration totals, arrival status, gender distribution, programme- and discipline-wise registrations and fees, along with batch-wise registration figures. Charts and summary figures make the information easier to scan.

02

MaggiMaker

Language: Python

MaggiMaker is a small, interactive console project that simulates the steps of making Maggi. The user can enter the water amount and temperature, choose the number of noodle packets, confirm the spices, and select optional ingredients. At the end, the program displays a summary of the choices.

Concepts practised: classes and objects, inheritance, methods, user input, conditions, loops, lists and dictionaries.

What I learned: I practised organising a program into methods and using object-oriented programming concepts to represent a familiar everyday process.
